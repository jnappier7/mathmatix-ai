The Answer verifier section above records on every answer attempt and is never gated on a flag. The STRUCTURED_TUTOR_RESPONSE path is dark by default — the structured tables are empty until the flag is on. Watch hard mismatch rate (model misclassified the turn) and backfill pose-success (Stage 5c.1 rescued a forgotten pose) to decide whether the flag is safe to ramp. Source: /api/admin/structured-tutor-metrics (admin-only, in-memory ring buffer of last 1000 turns, resets on restart). Counters are per-process — the inst tag in the header names the instance serving these numbers. If that hostname changes between refreshes, the app is running more than one instance and each holds its own slice.
